# Database latihan Chinook

`Chinook_MySql.sql` adalah salinan dari file yang disediakan untuk proyek ini. Skrip aslinya mengkreditkan Luis Rocha; salinan ketentuan lisensinya tersedia di [LICENSE-Chinook.md](LICENSE-Chinook.md). File ini membuat serta mengisi database `Chinook` untuk latihan API.

**Perhatikan baris awalnya:** `DROP DATABASE IF EXISTS Chinook;` akan menghapus database bernama `Chinook` yang sudah ada. Impor hanya di MySQL lokal khusus latihan setelah memeriksa isinya. Gunakan fitur impor SQL di HeidiSQL atau klien MySQL pilihanmu. Website PHP tidak membutuhkan database ini; hanya proyek `.NET` di `examples/chinook-api` yang memakainya.
