# Sumber pendalaman 19 materi awal

Referensi di bawah dibuka dan diperiksa pada 14 September 2026. Penjelasan, analogi perpustakaan/warung, penelusuran contoh, dan latihan ditulis ulang secara orisinal dalam Bahasa Indonesia; halaman resmi dipakai untuk memeriksa semantik API dan bahasa. Walkthrough merujuk contoh yang sudah ada di app/data/curriculum.php, bukan menyalin contoh dokumentasi.

Setiap materi memperoleh tiga bagian pendalaman (100–150 kata per bagian), penelusuran kode, dua jebakan umum, dua latihan bertingkat dengan petunjuk dan jawaban, serta tautan bacaan resmi. Tambahan estimasi waktu mencakup membaca dan mencoba latihan.

- Dictionary.TryGetValue dibuka memakai parameter view=net-10.0 setelah URL tanpa view gagal dibaca.

- Tidak ada perubahan contoh utama atau pin versi paket dilakukan dalam file pendalaman ini.
